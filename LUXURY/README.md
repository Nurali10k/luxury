# Maison Vale — Architecture & Real Estate

A responsive editorial portfolio for an independent luxury architecture and real estate studio. Built with React, Vite, Tailwind CSS v4, Lucide icons, and custom responsive CSS.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Highlights

- Full-screen architectural hero and six selected project cards
- Responsive mobile navigation and scroll-aware translucent header
- Project detail dialogs, client testimonial carousel, and enquiry form
- Lazy-loaded portfolio photography, scroll reveal animations, and reduced-motion support

The enquiry form is a frontend demo and needs a backend or form service to deliver messages.
